Your pocket
3D AI companion

Blobby is a cute, expressive blob that lives in your browser. It follows your cursor, reacts with real emotions, chats in your language, and even talks back through your microphone.

Get the code See it in action

Runs locally — npm install && npm run dev

Features

More than a chatbot

A personality-driven companion with a face that actually shows what it feels.

🫧

Living 3D avatar

A soft squishy blob rendered with Three.js that follows your pointer, blinks, wiggles, and pokes back when you click it.

🎭

Mood-driven expressions

Every AI reply is tagged with a mood — happy, sad, angry, surprised, wink, sleepy, silly — and Blobby's face changes to match.

🗣️

Speaks your language

English, Bengali, or Hinglish — Blobby automatically matches whatever language you use.

🎙️

Voice chat

Talk to Blobby out loud using your microphone via the browser's Web Speech API.

🧠

Real conversation memory

Per-session chat history powered by LangChain means Blobby remembers what you talked about.

✨

Customizable

Rename Blobby and give it a custom personality prompt — saved locally in your browser.

Quick start

Up and running in a minute

# clone & install
git clone https://github.com/Dip20/Blobby.git
cd blobby-chat
npm install

# add your Groq API key to .env
GROQ_API_KEY=your-groq-api-key

# run
npm run dev

# open http://localhost:3000
